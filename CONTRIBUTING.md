# Contributing

Thanks for wanting to help! Issues and pull requests are welcome.

- **Bugs and ideas:** open an [issue](https://github.com/EnigmaticZee/PawsOff/issues/new/choose).
  Questions are better in [Discussions](https://github.com/EnigmaticZee/PawsOff/discussions).
- **Code:** read [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) first: it covers the structure, the
  look, and the rules. The one that matters most: **there must always be a way to unlock.**
- Keep the Mac and Windows apps in step: a change on one side should land on the other.
- For UI changes, include before/after renders (`--render-previews`, see DEVELOPMENT.md).
- Security problems: please report privately (see [SECURITY.md](SECURITY.md)).
